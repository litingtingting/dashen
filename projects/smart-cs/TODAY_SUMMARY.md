## 💡 技术说明

### 80 端口授权

普通用户无法直接绑定 80 端口（需要 root），使用 `setcap` 授权：

```bash
sudo setcap 'cap_net_bind_service=+ep' ~/smart-cs/bin/smart-cs-v2
```

这样无需 root 权限即可监听 80 端口。

### 配置文件优先级

配置加载顺序：
1. 环境变量（最高优先级）
2. `.env` 文件
3. `configs/config.yml`

例如端口配置：
```bash
# .env
SERVER_PORT=80

# configs/config.yml
server:
  port: 80  # 会被环境变量覆盖
```
