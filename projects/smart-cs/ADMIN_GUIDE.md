## 📋 功能说明

### 1. 租户管理

**用途：** 管理使用客服系统的企业/店铺

**操作步骤：**
1. 点击"+ 新增租户"
2. 填写租户名称（如：某某淘宝店）
3. 选择平台类型（淘宝/微信/抖音）
4. 点击"创建"

**字段说明：**
| 字段 | 说明 |
|------|------|
| 租户名称 | 企业/店铺名称 |
| 平台类型 | 接入的客服平台 |
| 状态 | 正常/禁用 |

---

### 2. 用户管理

**用途：** 管理租户的操作员账号

**操作步骤：**
1. 点击"+ 新增用户"
2. 填写用户名、密码
3. 选择所属租户
4. 选择角色（管理员/操作员）
5. 点击"创建"

**角色说明：**
| 角色 | 权限 |
|------|------|
| 管理员 | 所有权限（包括删除租户） |
| 操作员 | 仅查看和回复对话 |

---

### 3. 对话管理

**用途：** 查看客户对话记录

**功能：**
- 查看所有对话历史
- 按租户筛选
- 按时间筛选
- 导出对话记录（开发中）

---

### 4. AI 训练

**用途：** 直接与 AI 客服对话，进行基础训练

**操作步骤：**
1. 切换到"AI 训练"标签页
2. 在输入框输入测试消息
3. 查看 AI 回复
4. 根据回复效果调整人设配置

**人设配置示例：**
```yaml
persona:
  name: 小智
  tone: 亲切友好
  greeting: 亲，您好呀~
  emojis: 😊🌟💕
  address_style: 亲
```

---

### 5. 套餐管理

**用途：** 管理订阅套餐（开发中）

**计划功能：**
- 创建套餐（每日对话限制、价格）
- 租户订阅管理
- 订单管理

## 🔧 API 接口

### 租户管理
```bash
# 获取租户列表
GET /api/tenants

# 创建租户
POST /api/tenants
{
  "name": "某某店铺",
  "type": "taobao"
}

# 删除租户
DELETE /api/tenants/:id
```

### 用户管理
```bash
# 获取用户列表
GET /api/users

# 创建用户
POST /api/users
{
  "username": "operator1",
  "password": "password123",
  "tenant_id": "xxx",
  "role": "operator"
}

# 用户登录
POST /api/users/login
{
  "username": "admin",
  "password": "admin123"
}
```

### 对话管理
```bash
# 获取对话列表
GET /api/conversations

# 创建对话
POST /api/conversations
{
  "tenant_id": "xxx",
  "customer_id": "xxx",
  "message": "你好"
}
```

### AI 测试
```bash
# 测试 AI 回复
POST /api/ai/test
{
  "message": "你好，我想咨询一下产品价格"
}
```

## ⚠️ 注意事项

### 安全
1. **修改默认密码** - 首次登录后立即修改
2. **HTTPS 配置** - 生产环境建议启用 HTTPS
3. **定期备份** - 数据库文件 `data/smart-cs.db`

### 性能
1. **对话清理** - 系统每天 02:00 自动清理 7 天前对话
2. **连接池** - 高并发场景建议配置数据库连接池

### 维护
1. **日志查看** - `logs/server.log`
2. **服务重启** - `pkill -f smart-cs-v2 && nohup ./bin/smart-cs-v2 ... &`
3. **健康检查** - `curl http://localhost/health`
